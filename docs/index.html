Features
Everything you need to take back control.
No GUI, no bloat. Just fast, transparent network monitoring that lives where you work.
🔍

TCP + UDP Monitoring

Detects every outbound connection via lsof with adaptive polling intervals. Supports both TCP and UDP protocols.

🛡

Real Firewall Rules

Deny decisions create actual pfctl rules via the macOS packet filter. Not a wrapper — real kernel-level blocking.

📋

Persistent Rules

Rules survive restarts. Support for wildcard patterns, scoped matching, import/export, and inline editing.

🌐

DNS Reverse Lookup

Automatically resolves IP addresses to hostnames with a built-in cache. Identifies Google, AWS, Cloudflare, and more.

📜

Connection History

Every decision logged to a JSONL file. Filter by process, action, or time. Full audit trail of network activity.

⚙

Daemon Mode

Install as a macOS launchd service for background monitoring. Start, stop, and check status from the CLI.

Commands
14 commands. Zero friction.
watch Start real-time connection monitoring
list-rules Display all saved allow/deny rules
edit-rule [id] Modify action, scope, host, or pattern
import-rules Import rules from JSON (merge or replace)
export-rules Export rules to JSON for backup/sharing
history View connection history with filters
firewall-status Check pfctl integration and show examples
list-firewall Show active pfctl blocking rules
firewall-cleanup Remove expired temporary rules
firewall-monitor Live firewall status feed
daemon install Set up launchd background service
daemon start|stop Control the background daemon
system-status Full system health and diagnostics
clear-rules Wipe all saved rules with confirmation
How It Works
Five steps. Full control.
1

Detect

lsof scans TCP + UDP connections every 2 seconds with adaptive intervals.

2

Match

New connections checked against saved rules with wildcard and scope matching.

3

Prompt

Unknown connections trigger an interactive terminal prompt with DNS context.

4

Enforce

Deny decisions create pfctl firewall rules that block at the kernel level.

5

Remember

Decisions are saved as persistent rules and logged to connection history.
